The general file viewer

Today ↵ on a file of the tree that is not Markdown opens the editor, and the phone says «el teléfono no abre». Here it opens a read-only viewer: line numbers, search, wrapping on demand. A .md keeps its rendered viewer and can show its source. Click the terminal and use the keys on the last row; the phone is at the right, with its own list of files. The buttons pick the case.

To approve

    
    
      
  1. Open. ↵ / l on a file of the tree opens it here; e (in the tree or in the viewer) opens the editor as ↵ does today. A .md still opens rendered; s flips it to its source and back.
    2. 
      
  2. Terminal viewer. Header with the path, lines and size; line numbers in a gutter; the same keys as the Markdown viewer (j k space b g G, / n N, y copies all, esc/q closes). New: w wraps; with wrapping off a long line is cut with › and h l move 8 columns; r rereads. Tabs are 4 columns.
    3. 
      
  3. Colour. A file of a known language (by extension, or name like Makefile, or a #! line) is coloured by its syntax, the same on both screens: keywords magenta, strings green, numbers and constants yellow, types and attributes cyan, functions blue, comments dim and italic. They are the theme's own six accents, so no theme gets a new colour and a light theme stays readable. The head of the file is coloured (up to 64 KiB, and for at most 0.3 s); the lines past that point show plain, so a big file never waits on its colours. An unknown extension shows plain too. The button above turns it off to compare. Here the colours are a rough imitation; the real ones come from a real grammar in the daemon.
    4. 
      
  4. Too big. Over 1 MiB the first MiB is shown, cut at a line end, and the last row says so in yellow. Nothing is paged in this part.
    5. 
      
  5. Binary. A binary or not-UTF-8 file shows the refusal with its size (from the listing) instead of a document; nothing is read into the viewer.
    6. 
      
  6. Phone. Tapping any file in Archivos opens it full-screen: monospace, line numbers that stay while you scroll sideways, text you can select, wrapping off by default with the ⏎ button (48 dp) to turn it on. No search on the phone in this part; select and copy only.
    7. 
      
  7. Read only. Neither side can change the file, and an open viewer does not follow the file when it changes on disk (r rereads in the terminal; the phone reopens it).
