Opening a folder and making a worktree

Two commands of the workspace level (they work at the panel level too): o opens a folder as a workspace and w makes a worktree of the project you are in. Click the terminal or tab into it. The workspaces here are notes, api (a git project) and its worktree feat/login. In the real client the folders are the ones of your disk.

  1. Open a folder: o. A browser that starts beside the project you are in (its parent folder). ↑/↓ move; → or tab goes into a folder, ← (or ⌫ with nothing typed) goes up, ~ goes home. Typing filters the folders of the one you are in, by letters in order, not by prefix. Folders already open show ●, git repositories say git. The first row opens the folder you are in. When what you typed is not a folder there is a row to create it. ↵ opens the folder as a workspace with one shell, or goes to it if it is already open. On the right, a look at the highlighted folder: its path, whether it is a repository, and what it holds.

  2. Make a worktree: w. A box with the name (the next free ws-N, replaced when you type), and under it, what will be made: the branch (feat/<name>), where it starts from (the branch of the workspace you are in) and the folder (<project>-wt/<name>). It says why when the name cannot be used (not a valid name, the worktree, the folder or the branch already exists). ↵ makes it and opens it; esc cancels. On a folder that is not a git repository it says so.
