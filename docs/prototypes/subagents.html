Seeing the subagents that run

Claude Code lists the agents working in the background and lets you open one to see what it is doing. jwn already has the list (⚙ n, ^B, /tasks: what it is, its time, x to stop) and draws the agent's card inside the chat. What it lacks is looking inside one while it works. Four ways, all with the clock running: pick a version, then use the keys in the terminal (click it first) or tap in the phone.
