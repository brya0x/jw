The footer, and the list of keys

The footer of the conversation says three things in this order, agents · mode · model, and a button for the keys: ^/ (a terminal cannot tell ^? from ^/: both are one key, the one with the slash, so the footer writes it as ^/). Click the terminal and press ^/ (or ? with the field empty), ⇧tab to change the mode (it works while Claude works), ^B to toggle the agents, esc to close. Pick the width to see how it gives way.
