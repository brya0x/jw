The tail of what a shell or a monitor prints

In the area of ^B the lit shell (or monitor) gets a salida section under comando and ahora: the last six lines it printed, newest at the bottom, dim. The daemon reads them from the file the engine writes for that task and sends them with the task; nothing else changes in the layout. Click the terminal and walk the lines with ↑↓; the first shell prints a new line every two seconds. The buttons below show the odd cases.
