The panel's folder follows the shell

The file tree does not change: it stays on the workspace. What follows the shell is the panel: the folder it points at. Today that folder is the one the pane was born in and never moves; if you cd .. out of it, the chip, the panel's context and the Claude you open from the panel still say the old place. Here the daemon watches the shell's real folder, so the chip says where you are, and a Claude you open (the claude half of the panel, or claude in the shell) starts there, with its @ references from there. Click the terminal and type in its shell: cd .., cd crates, cd ~, ls, claude.
